STORY

私のこれまで

新島 麻生

NIIJIMA ASAMI — 株式会社HELMIO 代表

自分に自信がなく、20代前半まで人前で話すことが大の苦手でした。
アナウンサーへの挑戦、挫折、転職。その振れ幅ごと、今のHELMIOにつながっています。

01 / START

人前で話すことが、
大の苦手だった。

小さい頃、とても内向的で、人前や目立つことが苦手。スポーツ中心で、大学はラクロスに明け暮れる。あるきっかけで、突然アナウンサーを目指す。

02 / JOB HUNT

アナウンサー就活、
落ちる。

専門に練習してきた候補者との差は大きく、受けた4社とも不合格。その後、スターダストプロモーションのキャスター部門を経て、4年かけてアナウンサーへ。

03 / NHK

NHKで4年、
アナウンサーを経験。

ニュースキャスター、取材、インタビュー、生放送を経験。「伝える」を仕事にし、人とのつながりや人生の選択肢が広がりました。

04 / DROP

「アナウンサーは、
潰しが効かない。」

次に挑戦したかったビジネス・スタートアップの世界へ。ところが、キャリアは思うようには進みませんでした。

05 / 140 TALKS

転職で、
約140社と話した。

カジュアル面談を重ね、さまざまな企業・仕事・人に出会い、キャリアの構造を学びました。

06 / HELMIO

そして今、
HELMIOへ。

キャリアの可能性を広げること、「伝える」の教育分野に携わりたいと思い、HELMIOを設立。
